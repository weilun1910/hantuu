# hantuu releases

What each version of hantuu adds, newest first.

- [2.1](v2.1.md), not released yet. Reader mode right in the chat, light mode, pinned chats and a sidebar that survives updates.
- [2.0](v2.0.md), 5 November 2026. Agent status, the review tabs, agents that keep running after you quit, and a worktree per chat.
- [1.0](v1.0.md), 5 November 2026. The first version, with the sidebar, Ghostty terminals and the reader.
